[title] This is Level Doctor. I shipped a game-jam game with twenty levels, and tuning them by hand took three rounds of guessing. Level Doctor is an agent that writes its own bot players, playtests the game thousands of times, finds out why players lose, and fixes the levels.

[code] Step one: the agent writes code. A language model reads the game's rules and writes three bots, casual, regular and expert, as JavaScript. The agent runs them in the real game and feeds the measured pass rates back until skill ranks correctly. Here that took 5 rounds.

[run] Step two: it runs its code. The real, unmodified game runs headless with a virtual clock, a fraction of a second per level, and the same seed replays byte for byte. 6,560 playtests inside a CreateOS sandbox, each number with a ninety-five percent error bar.

[stack] Here's the stack. Every batch runs in a CreateOS sandbox with its network locked down, because the bots are code an LLM wrote. A request from inside the sandbox fails. And the same seed gives the same result in the sandbox as on my laptop, hash for hash.

[chaos] Step three is a metric I couldn't find in any existing tool: the Chaos Ratio. This is Earthquake. Same seed, same bot. The only difference: the fourth drop moved by one ten-thousandth of a unit. One run wins. The other loses.

[chaosChart] Do that for every level and losses split into two kinds. On Bouncy Castle and Frozen Friends, they're dice rolls. On Tight Squeeze, they're traps a designer can fix. Pass rate alone can't tell them apart.

[tempo] Step four: twist exposure. This level is called Bass Drop. A bot at typical bot speed clears it in 16 seconds, before the first bass drop. It calls the level fine without ever hearing its twist. Level Doctor's bots play at human speed, and every twist gets an exposure check.

[fix] Finally, the fix. One batch with unlimited drops gives the pass rate for every possible drop limit. The agent picks the limit that hits the target and re-tests it with fresh seeds. 6 levels re-tuned, 5 verified within error bars.

[orbital] And it isn't tied to one game. On an endless arcade game, the same agent wrote new bots, found which difficulty knob actually matters, and tuned it so a regular player reaches 20 seconds about half the time, verified.

[outro] Level Doctor. Ten years of triple-A playtesting research, in five minutes, for indie web games. Built on CreateOS and Stripe Projects.
